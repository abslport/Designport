BAYU REFOKUS-STYLE STARTER

Isi file:
- index.html  = struktur website
- style.css   = dark visual, loader, orbit, dashboard, project, footer
- main.js     = loading cepat, orbit mouse movement, hover preview, counter

Cara pakai lewat HP:
1. Extract ZIP ini.
2. Upload 3 file ke repo GitHub kamu.
3. Pastikan index.html, style.css, main.js ada di root repo.
4. Commit changes.
5. Deploy/buka di Vercel atau GitHub Pages.

Ini versi starter coding-only, tanpa asset Refokus dan tanpa model 3D.
Tahap berikutnya bisa di-upgrade dengan GSAP + Three.js.
